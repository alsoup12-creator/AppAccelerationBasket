# 应用加速箩筐

一个面向 Windows 的应用级代理启动辅助工具。它可以从已安装应用、桌面快捷方式、文件或正在运行的程序中选择应用，再以“专用代理”或“普通网络”方式逐个启动。

> 当前版本：v0.1.1（测试版）

## 它解决什么问题

部分 VPN 的“智能模式”可能会把不需要代理的应用也带入代理线路。应用加速箩筐通过启动参数和代理环境变量，让用户自行选择少量需要走指定本地代理的应用，同时尽量让箩筐外应用保持原来的网络方式。

本工具不是 VPN，也不提供节点、账号或网络线路。使用前需要自行准备能够工作的本地 HTTP 或 SOCKS5 代理。

## 主要功能

- 单击选择一个应用，分别以专用或普通方式启动。
- Codex 桌面版专门适配：每次启动前重新识别安装路径，更新期间短暂重试，并检查专用启动的主进程是否收到代理参数。
- Chrome、Edge、Brave、Opera、Vivaldi 使用独立浏览器配置目录。
- 扫描开始菜单、Windows 安装记录和 Microsoft Store 应用。
- 支持搜索已安装应用，并显示“已适配 / 通用尝试 / 仅识别”状态。
- 可保存并打开多个 VPN 程序，但不会代替用户选择节点或模式。
- 阻止非浏览器应用被重复启动。
- 修改 Windows 用户代理前自动备份，并提供恢复按钮。

## 兼容性说明

| 类型 | 当前能力 |
| --- | --- |
| Codex | 普通模式经 Windows 应用入口启动；专用模式直接启动当前安装包程序，并检查代理参数。登录与实际请求线路仍需验证 |
| Chromium 浏览器 | 已适配，使用独立专用窗口和配置目录 |
| 支持代理环境变量的应用 | 通用尝试，是否生效取决于应用自身 |
| Microsoft Store / 系统应用 | 可以识别，但没有明确桌面启动程序时不能加入 |
| 游戏、反作弊软件、系统服务 | 不建议使用，当前版本不支持 |

“识别到应用”不等于“保证代理生效”。通用应用是否读取 `HTTP_PROXY`、`HTTPS_PROXY` 或 `ALL_PROXY`，需要用户实际验证。

Codex 与浏览器的启动路径不同：专用浏览器使用独立配置目录和 Chromium 代理参数；Codex 保留原有应用资料，专用模式向 Codex 进程传入代理参数和环境变量。若 Windows 或今后的 Codex 版本禁止直接启动安装包内的程序，箩筐会报告失败，不会把普通启动标成专用加速。

## 首次登录与浏览器说明

- 普通桌面应用：登录和应用代理是两段独立的网络过程。首次登录或身份验证如需完整网络环境，可先用可用线路完成登录；登录后完全退出应用，再通过箩筐专用启动。是否保留登录状态由应用决定。
- Chromium 浏览器：箩筐使用独立的浏览器配置目录，普通 Chrome / Edge 中的账号、Cookie 和扩展不会自动复制过来。首次使用时，应先启动自己的 VPN，再从箩筐打开专用浏览器窗口，并在这个窗口里完成一次登录。
- 从箩筐专用浏览器内部新建的标签页或窗口，通常会继续使用该专用线路；从桌面、任务栏或其他应用打开的普通浏览器窗口，则继续使用原来的网络方式。

简而言之：普通桌面应用可以先完成正常登录再通过箩筐启动；浏览器则需要在箩筐创建的独立窗口中重新登录一次。

Codex 的 ChatGPT 登录可能打开另一个浏览器窗口。Codex 进程上的代理设置不会自动传给该窗口；如遇登录页无法打开或要求重新登录，请检查该浏览器自身的网络线路。

## 下载和使用

1. 在 GitHub 项目右侧进入 **Releases**，下载 `AppAccelerationBasket-v0.1.1-windows-x64.zip`。
2. 解压压缩包，不要直接在 ZIP 内运行。
3. 先启动自己的 VPN，并确认它提供的本地 HTTP 或 SOCKS5 地址和端口。
4. 打开 `应用加速箩筐.exe`。
5. 添加或选择应用。Codex 完全退出后，点击“专用代理启动 Codex（验证参数）”；其他应用点击“专用加速启动选中应用”。
6. 需要恢复原来的 Windows 代理时，点击“仅恢复 Windows 系统代理”。

完整操作说明见发行包中的 `使用说明.txt`。

## 安全和隐私

- 不要求管理员权限。
- 不安装驱动、服务、证书或浏览器扩展。
- 不上传已安装应用列表、程序路径或代理配置。
- 配置和独立浏览器资料保存在 `%LOCALAPPDATA%\AppAccelerationBasket`。
- “测试线路”会通过用户选择的代理向 `api.openai.com:443` 发起连接握手，用于验证代理可用性。
- 专用启动时，如果 Windows 用户代理已开启，工具会先备份再关闭；恢复按钮会还原备份。

当前个人发布版本没有商业代码签名证书，因此 Windows 可能显示“未知发布者”或 SmartScreen 提示。请只从本项目的 GitHub Releases 下载，并可用发行页公布的 SHA256 校验文件完整性。

更多边界说明见 [SECURITY.md](SECURITY.md)。

## 已知限制

- 不是 TUN/WFP 透明分流工具。
- 不能向已经运行的普通应用动态注入代理。
- 不支持需要用户名和密码认证的代理。
- 通用应用可能忽略代理环境变量。
- 关闭并重开箩筐后，只能判断应用是否运行，无法追溯它上次由哪种模式启动。
